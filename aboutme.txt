TECHNICAL INTERVIEW QUESTIONS

--- PYTHON ---

Q: What is the difference between a list and a tuple in Python?
A: A list is mutable, so its items can be changed after creation, and it is written with square brackets. A tuple is immutable, so it cannot be changed once created, and it is written with parentheses. Tuples are used for fixed data and are slightly faster and safer to share.

Q: What is a dictionary in Python?
A: A dictionary stores data as key-value pairs, like {"name": "Vamsi"}. Looking up a value by its key is very fast on average, which makes dictionaries ideal for structured data and for converting to JSON.

Q: What is a decorator in Python?
A: A decorator is a function that wraps another function to add extra behavior, such as logging or timing, without changing the original function's code. It is applied with the @ symbol above the function.

Q: What are the four pillars of OOP?
A: Encapsulation (bundling data and methods and hiding internal details), abstraction (showing only what is necessary), inheritance (a class reusing another class's features), and polymorphism (the same method behaving differently depending on the object).

--- JAVA ---

Q: What is the difference between JDK, JRE, and JVM?
A: The JVM runs Java bytecode. The JRE contains the JVM plus the libraries needed to run Java programs. The JDK contains the JRE plus development tools like the compiler, so it is what developers install to write and build Java programs.

Q: What is the difference between an abstract class and an interface in Java?
A: An abstract class can have both implemented and unimplemented methods and fields, and a class can extend only one. An interface defines a contract of methods that a class must implement, and a class can implement many interfaces. Use an abstract class for shared code and an interface for shared capabilities.

--- JAVASCRIPT ---

Q: What is the difference between var, let, and const?
A: var is function-scoped and can be redeclared. let is block-scoped and can be reassigned. const is block-scoped and cannot be reassigned. Modern code prefers const by default and let when a value must change.

Q: What is the difference between == and === in JavaScript?
A: == compares values after converting types, so "5" == 5 is true. === compares both value and type with no conversion, so "5" === 5 is false. Using === avoids unexpected bugs.

Q: What are promises and async/await?
A: A promise represents a value that will be available in the future, used for asynchronous work like API calls. async/await is cleaner syntax built on promises that lets asynchronous code read like normal step-by-step code.

Q: What is a closure?
A: A closure is a function that remembers the variables from the place where it was created, even after that outer function has finished running. It is used for private data and for callbacks.

--- REACT AND NODE.JS ---

Q: What is the Virtual DOM in React?
A: It is a lightweight copy of the real DOM kept in memory. When state changes, React compares the new virtual DOM with the previous one and updates only the parts of the real DOM that changed, which makes updates efficient.

Q: What is the difference between props and state in React?
A: Props are inputs passed from a parent component to a child and are read-only. State is data managed inside a component that can change over time and causes the component to re-render when updated.

Q: What are useState and useEffect?
A: useState lets a function component store and update state. useEffect lets a component run side effects, such as fetching data or setting up a timer, after it renders, and it can re-run when chosen values change.

Q: What is Node.js?
A: Node.js is a JavaScript runtime built on Chrome's V8 engine that lets JavaScript run on the server. It uses an event-driven, non-blocking model, which makes it good for handling many requests efficiently, such as in APIs.

--- REST APIs ---

Q: What is a REST API?
A: A REST API lets a client and a server communicate over HTTP using resources and standard methods: GET to read, POST to create, PUT or PATCH to update, and DELETE to remove. It is stateless, meaning each request carries all the information the server needs, and data is usually exchanged as JSON.

Q: What are common HTTP status codes?
A: 200 means success, 201 means a resource was created, 400 means a bad request, 401 means unauthorized, 404 means not found, 500 means a server error, and 503 means the service is unavailable or overloaded. Vamsi came across 503 errors while building DigiVam and handled them with retries and a backup model.

--- DATABASES ---

Q: What is the difference between MySQL and MongoDB?
A: MySQL is a relational (SQL) database that stores data in tables with a fixed schema and uses joins to connect related data. MongoDB is a NoSQL document database that stores flexible JSON-like documents, which suits changing or nested data. Choose MySQL for structured, relational data and MongoDB for flexible, document-style data.

Q: What are a primary key and a foreign key?
A: A primary key uniquely identifies each row in a table. A foreign key is a column that refers to the primary key of another table, creating a relationship between the two tables.

--- ANDROID, KOTLIN AND FLUTTER ---

Q: What is the difference between StatelessWidget and StatefulWidget in Flutter?
A: A StatelessWidget does not change after it is built, such as a fixed label or icon. A StatefulWidget has state that can change over time, such as a counter or a form, and rebuilds its UI when that state updates.

Q: What is null safety in Kotlin?
A: Kotlin separates nullable and non-nullable types, so a normal variable cannot hold null unless it is declared with a question mark, like String?. This catches many null pointer errors at compile time instead of at runtime.

Q: What is the Android Activity lifecycle?
A: An Activity is a single screen of an app. Its main lifecycle methods are onCreate, onStart, onResume, onPause, onStop, and onDestroy, which let the app set up, show, pause, and clean up the screen as the user moves around.

--- AI AND MACHINE LEARNING ---

Q: What is the difference between supervised and unsupervised learning?
A: Supervised learning trains on labeled data, where the correct answers are known, such as predicting prices or classifying emails. Unsupervised learning finds patterns in unlabeled data, such as grouping customers into clusters.

Q: What is overfitting and how can it be reduced?
A: Overfitting happens when a model learns the training data too closely, including its noise, and performs poorly on new data. It can be reduced by using more data, simplifying the model, using regularization, applying cross-validation, or stopping training earlier.

Q: Why do we split data into training and testing sets?
A: The model learns from the training set, and the test set is data it has never seen, used to check how well it will perform in the real world. This gives an honest measure of its performance.

Q: How is a classification model evaluated?
A: Common metrics are accuracy (overall correct predictions), precision (how many predicted positives were correct), recall (how many actual positives were found), and the F1 score, which balances precision and recall. A confusion matrix shows these results in detail.

--- WEB AND DESIGN ---

Q: What is the difference between Flexbox and CSS Grid?
A: Flexbox arranges items in one direction, either a row or a column, and is great for things like navigation bars and button rows. Grid arranges items in rows and columns at the same time, and is better for full page or card layouts.

Q: How do you make a website responsive?
A: Use a flexible layout with Flexbox or Grid, relative units like percentages instead of fixed pixels, images with max-width: 100%, and CSS media queries to change the layout for tablets and phones. It is also important to include the viewport meta tag.

Q: What is the difference between UI and UX?
A: UI, or user interface, is how a product looks: colors, typography, buttons, and layout. UX, or user experience, is how it feels to use: how easy, clear, and efficient the journey is. Good products need both.

Q: What is the difference between Git and GitHub?
A: Git is a version control tool that tracks changes to code on your computer. GitHub is an online platform that hosts Git repositories so people can store, share, and collaborate on code, and it can also host websites such as Vamsi's portfolio.
